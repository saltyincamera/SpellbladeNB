# Spellblade Legends: New Blood

เกม MMORPG 3 มิติบนเบราว์เซอร์ (three.js)

**เล่นเลย:** https://saltyincamera.github.io/spellbladenb/

## ID และเซฟ
- สร้าง ID แล้วจะได้ **รหัสเซฟ** ให้จดเก็บไว้ ใช้คู่กับ ID เพื่อ Login จากเครื่องอื่น
- ตัวละครเซฟไว้บนเซิร์ฟเวอร์ (Google Apps Script + Google Sheets) เล่นต่อได้ทุกเครื่อง
- เล่นโดยไม่ใช้ ID ก็ได้ เซฟจะอยู่ในเครื่องนั้นเท่านั้น
